🧠 Engineering philosophy
Don't start with the technology. Start with the pain.

Understand the workflow. Find the bottleneck. Ship the smallest useful solution. Measure what changed. Iterate.

I'm especially interested in applied AI that has to work in the real world—where latency, reliability, cost, usability, and messy data matter as much as model quality.
